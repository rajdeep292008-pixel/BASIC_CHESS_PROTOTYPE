# Vantage Chess Pro - Interactive AI Sandbox Prototype

A luxury, dark-themed responsive chess web application prototype engineered for smooth client-side gameplay dynamics. The application interfaces with standard algorithmic logic loops to simulate interactive chess battle states against a localized computing node.

## 🌟 Key Integrated Modules
- **Dynamic Side Allocation:** Interactive setup screen module allowing the player to select White or Black, instantly auto-orienting the board viewport vector.
- **Bi-Directional Time Engine:** Integrated dual-timer system tracking player and opponent clock pools (10-minute rapid matrix) using system time-slice intervals with active turn highlighting.
- **Real-Time PGN Move Log:** An automated live history rendering panel displaying formal chess algebraic notations for both sides with absolute scroll locking.
- **Randomized AI Engine Shell:** An integrated local move generation script that calculates all available legal flight/capture variants and executes responsive actions with simulated delay factors.

## 🛠️ Built With
- **Chess.js v0.10.3:** Core rule verification engine handles checkmate detection, draw metrics, and state vectors.
- **Chessboard.js v1.0.0:** Highly optimized UI piece layout rendering with real-time responsive drag-and-drop snapping hooks.
- **Tailwind CSS & jQuery Core:** Managed glassmorphism user layer design matrix and asynchronous UI tracking.
